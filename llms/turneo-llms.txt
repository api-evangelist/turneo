# Turneo

> Turneo is an operating system for hotel experiences and services. It digitizes the activities, spa & wellness, dining, rentals, transfers, and tickets a hotel offers, makes them bookable across guest touchpoints, and deploys AI agents to automate operations. Partners integrate via the v2 REST API and embeddable Turneo Elements widgets.

## API

- [Turneo v2 API](https://www.turneo.com/developers): REST booking API at https://api.turneo.co, authenticated with an X-API-Key header. Search experiences, retrieve options and availability, and assemble/confirm booking orders.

## Endpoints

- GET /v2/experiences — search experiences (storeId, country, city, from, until)
- GET /v2/experiences/{experienceId}/options — list options/pricing
- GET /v2/experiences/{experienceId}/availability/dates — available dates
- GET /v2/experiences/{experienceId}/availability/slots — available time slots
- POST /v2/booking-orders — create a booking order
- POST /v2/booking-orders/{id}/add — add bookings
- POST /v2/booking-orders/{id}/remove — remove bookings
- POST /v2/booking-orders/{orderId}/confirm — confirm and purchase
